# LearnixAI

LearnixAI is a multilingual educational AI assistant designed to help students learn more effectively.

The primary language of LearnixAI is English, but it can automatically respond in the user's language and adapt to different learning styles.

## Vision

Learning should be accessible, interactive, and personalized.

LearnixAI aims to become a smart learning companion that helps students:

- Understand concepts
- Practice with quizzes
- Improve language skills
- Stay motivated
- Track learning progress

## Features

### Current
- Educational assistant
- Multi-language responses
- Language-aware conversations

### Planned
- Automatic language detection
- English learning mode
- Quiz generation
- Study tracking
- Personalized recommendations
- Subject-specific tutoring
- Learning analytics

## Supported Languages

Currently planned:

- English
- Japanese
- Chinese
- Spanish
- French
- German

The response language will automatically adapt to the user's input language whenever possible.

**User**

> Explain photosynthesis.

**LearnixAI**

> Photosynthesis is the process by which plants convert sunlight into chemical energy.
